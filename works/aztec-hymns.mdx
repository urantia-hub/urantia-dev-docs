The API serves **Rig Veda Americanus: Sacred Songs of the Ancient Mexicans** (Daniel G. Brinton, 1890) as JSON, one passage at a time, by the reference people use. Twenty Aztec hymns to the gods, recorded by Sahagún. It has 112 passages in 20 hymns. No key and no account.

## Get a passage

```bash
# Aztec Hymn 1.3
curl https://api.urantia.dev/scriptures/aztec-hymns/1.3
```

```json
{
  "data": {
    "corpus": {
      "slug": "aztec-hymns",
      "title": "Rig Veda Americanus: Sacred Songs of the Ancient Mexicans",
      "translator": "Daniel G. Brinton",
      "year": 1890
    },
    "passages": [
      {
        "ref": "Aztec Hymn 1.3",
        "division": 1,
        "text": "The Dart-Hurler is an example to the city, as he sets to work. He who commands in battle is called the representative of my God."
      }
    ]
  }
}
```

The slug `aztec-hymns`, the id `aztec-hymns-brinton-1890`, and the prefix `aztec hymn` all name this text.

## References

Hymn and verse, `Aztec Hymn 1.3`.

`GET /scriptures/aztec-hymns` lists every hymn with its first and last reference.

## Search

```bash
# By meaning
curl -X POST https://api.urantia.dev/scriptures/search/semantic \
  -H "Content-Type: application/json" \
  -d '{"q":"your question","corpus":"aztec-hymns","limit":5}'
# By keyword
curl 'https://api.urantia.dev/works/search?q=your%20words&work=aztec-hymns'
```

Each passage also links to the closest paragraphs of the Urantia Papers: `GET /scriptures/aztec-hymns/1.3/urantia-parallels`. The [world religions guide](/scriptures) explains how the links are made, and the [MCP server](/mcp-servers) has the same calls for AI agents.
