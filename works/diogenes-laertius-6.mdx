The API serves **Lives of Eminent Philosophers, Book 6: The Cynics** (R. D. Hicks, 1925) as JSON, one passage at a time, by the reference people use. The lives and sayings of Diogenes and the other Cynic philosophers. It has 105 passages in 1 book. No key and no account.

## Get a passage

```bash
# DL 6.20
curl https://api.urantia.dev/scriptures/diogenes-laertius-6/6.20
```


The slug `diogenes-laertius-6`, the id `diogenes-laertius-6-hicks-1925`, and the prefix `dl` all name this text.

## References

Book and section, `DL 6.20`. Each section also names the life it belongs to, such as Diogenes.

`GET /scriptures/diogenes-laertius-6` lists every book with its first and last reference.

## Search

```bash
# By meaning
curl -X POST https://api.urantia.dev/scriptures/search/semantic \
  -H "Content-Type: application/json" \
  -d '{"q":"your question","corpus":"diogenes-laertius-6","limit":5}'
# By keyword
curl 'https://api.urantia.dev/works/search?q=your%20words&work=diogenes-laertius-6'
```

Each passage also links to the closest paragraphs of the Urantia Papers: `GET /scriptures/diogenes-laertius-6/6.20/urantia-parallels`. The [world religions guide](/scriptures) explains how the links are made, and the [MCP server](/mcp-servers) has the same calls for AI agents.
