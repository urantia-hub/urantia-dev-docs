This tutorial shows you how to build a bot that fetches random inspiring quotes from the Urantia Papers and shares them daily via Discord, Slack, email, or social media. Takes ~10 minutes to build.

<Card title="Try the Live Demo" icon="play" href="https://demo.urantia.dev">
  See the random quote feature in action at demo.urantia.dev
</Card>

## What You'll Build

A bot that:
1. Fetches a random paragraph from the Urantia Papers
2. Formats it with the reference citation
3. Posts it to your chosen platform (Discord, Slack, email, etc.)

No API key needed — the Urantia API is completely free.

## Prerequisites

- **Node.js 18+** or **Python 3.10+**
- A platform to post to (Discord webhook, Slack webhook, email service, etc.)

    // fetch-quote.js
    async function getDailyQuote() {
      const response = await fetch('https://api.urantia.dev/paragraphs/random');
      const data = await response.json();
      
      return {
        text: data.text,
        reference: data.standardReferenceId,
        paperTitle: data.paperTitle,
        url: `https://urantiahub.com/api/redirect/papers/by-standard-reference-id/${data.standardReferenceId}`
      };
    }

    async function postToDiscord(webhookUrl) {
      const quote = await getDailyQuote();
      
      const message = {
        embeds: [{
          title: "Daily Urantia Quote",
          description: `"${quote.text}"`,
          fields: [
            {
              name: "Reference",
              value: `[${quote.reference}](${quote.url})`,
              inline: true
            },
            {
              name: "Paper",
              value: quote.paperTitle,
              inline: true
            }
          ],
          color: 0x3B82F6,
          footer: { text: "Powered by api.urantia.dev" }
        }]
      };

      await fetch(webhookUrl, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify(message)
      });
    }

    // Run it
    const DISCORD_WEBHOOK = 'YOUR_WEBHOOK_URL_HERE';
    postToDiscord(DISCORD_WEBHOOK)
      .then(() => console.log('Quote posted!'))
      .catch(err => console.error('Error:', err));

## How It Works

### 1. Fetch a Random Paragraph

```bash
curl https://api.urantia.dev/paragraphs/random
```

Returns a random paragraph with:
- `text` — The paragraph content
- `standardReferenceId` — Citation (e.g., "107:0.1")
- `paperTitle` — The paper's title
- `paperId`, `sectionId`, `paragraphId` — Numeric IDs

### 2. Format for Your Platform

The examples above show Discord and Slack formatting. Adapt for your platform:

## Enhance Your Bot

### 1. Filter by Topic

Search for quotes about specific topics instead of random:

```javascript
async function getTopicQuote(topic) {
  const response = await fetch('https://api.urantia.dev/search', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ q: topic, type: 'and', limit: 10 })
  });
  
  const data = await response.json();
  // Pick a random result from the top 10
  const randomIndex = Math.floor(Math.random() * data.results.length);
  return data.results[randomIndex];
}

// Usage
const quote = await getTopicQuote('love');
```

### 2. Add Audio

Every paragraph has audio narration:

```javascript
async function getQuoteWithAudio(ref) {
  const response = await fetch(`https://api.urantia.dev/paragraphs/${ref}`);
  const data = await response.json();
  
  // Get audio URL (tts-1-hd/nova covers every paragraph)
  const audioUrl = data.audio?.['tts-1-hd']?.nova?.url;
  
  return { ...data, audioUrl };
}
```

### 3. Track Quote History

Store sent quotes to avoid duplicates:

```javascript
const sentQuotes = new Set();

async function getUniqueQuote() {
  let attempts = 0;
  let quote;
  
  do {
    const response = await fetch('https://api.urantia.dev/paragraphs/random');
    quote = await response.json();
    attempts++;
  } while (sentQuotes.has(quote.standardReferenceId) && attempts < 10);
  
  sentQuotes.add(quote.standardReferenceId);
  return quote;
}
```

### 4. Theme Days

Rotate topics by day of week:

```javascript
const themes = {
  0: 'love',        // Sunday
  1: 'faith',       // Monday
  2: 'service',     // Tuesday
  3: 'truth',       // Wednesday
  4: 'wisdom',      // Thursday
  5: 'prayer',      // Friday
  6: 'worship'      // Saturday
};

async function getThemedQuote() {
  const dayOfWeek = new Date().getDay();
  const topic = themes[dayOfWeek];
  return getTopicQuote(topic);
}
```

## Troubleshooting

**Rate limits:** The API allows 100 requests/minute per IP. For a daily bot, this is more than enough. If you hit limits, add retry logic with exponential backoff.

**Quote is too long:** Some paragraphs are lengthy. Truncate with `text.substring(0, 300) + '...'` or filter by character count before posting.

**Want specific topics?** Use `GET /search?q=...` or `GET /search/semantic?q=...` to pick paragraphs on a theme, and quote the text the API returns.
