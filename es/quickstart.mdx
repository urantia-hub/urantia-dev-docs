Todas las llamadas de esta página funcionan tal como están. No necesitas una clave.

## Pide un párrafo

Agrega `lang=es` para recibir el texto en español.

<Tabs>
  <Tab title="cURL">
    ```bash
    curl "https://api.urantia.dev/paragraphs/1:0.1?lang=es"
    ```
  </Tab>
  <Tab title="JavaScript (fetch)">
    ```javascript
    const response = await fetch('https://api.urantia.dev/paragraphs/1:0.1?lang=es')
    const { data } = await response.json()

    console.log(data.text)
    console.log(data.translation) // { method: 'machine', license: 'CC0-1.0', review: 'auto_checked' }
    ```
  </Tab>
  <Tab title="Python">
    ```python
    import requests

    response = requests.get('https://api.urantia.dev/paragraphs/1:0.1', params={'lang': 'es'})
    data = response.json()['data']

    print(data['text'])
    print(data['translation'])
    ```
  </Tab>
  <Tab title="TypeScript SDK">
    ```typescript
    import { UrantiaAPI } from '@urantia/api'

    const api = new UrantiaAPI()
    const { data } = await api.paragraphs.get('1:0.1', { lang: 'es' })

    console.log(data.text)
    ```

    Instalación: `npm install @urantia/api`
  </Tab>
</Tabs>

Una referencia como 1:0.1 significa documento 1, sección 0, párrafo 1.

## Busca en el texto en español

La búsqueda por palabras encuentra una palabra con acentos o sin ellos ("religion" encuentra "religión"):

```bash
curl "https://api.urantia.dev/search?q=Ajustador%20del%20Pensamiento&lang=es"
```

La búsqueda por significado acepta una pregunta en español o en inglés, y devuelve los párrafos en español:

```bash
curl "https://api.urantia.dev/search/semantic?q=%C2%BFQu%C3%A9%20es%20el%20alma%3F&lang=es"
```

## Lee un documento completo

```bash
curl "https://api.urantia.dev/papers/1?lang=es"
curl "https://api.urantia.dev/toc?lang=es"
```

El primero devuelve el documento 1 con todos sus párrafos. El segundo devuelve el índice: las partes y los títulos de los documentos.

## Conecta un agente de IA (MCP)

El servidor MCP da a un agente 26 herramientas para buscar y leer el texto. No necesita clave:

```
https://api.urantia.dev/mcp
```

Las herramientas de documentos, párrafos y búsqueda aceptan `lang: "es"`. Para configurarlo en Claude Code, Cursor u otra herramienta, consulta [MCP Servers](/mcp-servers) (en inglés).

## La etiqueta de traducción

Cada párrafo en español trae `language: "es"` y un campo `translation`:

| Campo | Significado |
|---|---|
| `translation.method` | Siempre `machine` (traducción automática) |
| `translation.license` | Siempre `CC0-1.0` |
| `translation.review` | `auto_checked`: las revisiones automáticas no encontraron problemas. `needs_review`: una revisión marcó el párrafo, y conviene que una persona lo lea antes de usarlo |

No presentes el texto en español como una traducción oficial ni como una traducción humana.
