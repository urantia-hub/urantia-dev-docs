## For AI agents

Connect the MCP server and the agent gets 19 tools for search, lookup, and cross-references. No key needed.

```
https://api.urantia.dev/mcp
```

- [Set up the MCP server](/mcp-servers) in Claude, Cursor, or another client
- [Agent guide](/ai-agents): the recommended flow from table of contents to search to context
- Listed on [Smithery](https://smithery.ai/servers/urantiahub/urantia-papers) and [Glama](https://glama.ai/mcp/connectors/dev.urantia/urantia-papers)

## Features

- **Full-text search** with ranked results across all paragraphs
- **Semantic search** using vector embeddings for meaning-based queries
- **MCP servers** at [`/mcp-servers`](/mcp-servers): 19 tools + 2 resources + 2 prompts for Claude, Cursor, and other AI agents
- **Function-calling schemas** at `/tools/openai` and `/tools/anthropic`: drop-in tool definitions for the OpenAI and Anthropic SDKs
- **Three paragraph ID formats** auto-detected from the reference string
- **4,400+ entities**: beings, places, orders, races, religions, concepts
- **Audio narration** with multiple TTS models and voices per paragraph
- **OpenAPI spec** at `/openapi.json` for client generation
- **Postman workspace** at [postman.com/urantia-dev/urantia-papers](https://www.postman.com/urantia-dev/urantia-papers): 28 requests that run as is
- **No authentication required**: no key and no sign-in
